# 时间转换语料 V2

在网页“模型训练 → 中文时间转换”中导入本文件夹，或分别上传三份 JSONL。
不要点击“生成示例语料”覆盖导入结果，该按钮仍生成原版语料。
保持默认训练参数，训练完成后点击“启用模型并测试”。修改数据不会更新旧模型。

## 修改内容

原数据已经包含每个整点的省略分钟、整、零分三种表达，但 15:00 和 23:00 的全部表达在测试集。
本版把这两个时间的六条样例移入训练集：

- 下午三点 / 下午三点整 / 下午三点零分 → 15:00
- 晚上十一点 / 晚上十一点整 / 晚上十一点零分 → 23:00

对应将 14:00、22:00 的全部整点表达从训练集移入测试集，保留上午一点、上午九点整点组在验证集。
完整保留原有 1449 条样例，未复制重复行；训练 1163 条、验证 143 条、测试 143 条。
每个小时与分钟组合的所有同义表达始终在同一个集合，已通过网页后端的数据校验。

## 验收

训练后手动检查“下午三点”和“晚上十一点”，它们属于已学习样例的回归检查，不再算独立测试题。
查看新测试集准确率，并关注未参与这次训练的“下午二点”、“晚上十点”及其整/零分表达。

本版只修改数据划分，没有增加整点采样权重，没有重新训练。原模型的 98.60% 成绩不适用于本版。
原始语料、模型和报告完整保留在相邻的 time-task 文件夹。
